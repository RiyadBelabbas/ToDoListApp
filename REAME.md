# Gestionnaire de Tâches Console (To-Do List)

Ce projet est une application console simple écrite en C# pour gérer une liste de tâches.

## Fonctionnalités
- Ajouter une tâche.
- Afficher toutes les tâches.
- Marquer une tâche comme terminée.
- Supprimer une tâche.
- Quitter l'application.

## Comment utiliser
1. Clonez ce dépôt.
2. Compilez et exécutez le fichier `Program.cs`.
3. Suivez les instructions affichées dans la console.

## Améliorations possibles
- Ajouter la persistance des données en utilisant un fichier texte ou JSON.
- Ajouter des catégories ou des priorités pour les tâches.
- Créer une interface graphique (Windows Forms ou WPF).
